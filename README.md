# 備忘録 — 漫画备份站

一个纯 HTML / CSS / JS 的静态漫画归档 + 在线阅读站，不依赖任何构建工具，
可以直接丢进 GitHub Pages（或任何静态托管）使用。

## 目录结构

```
manga-site/
├── index.html              首页：全部系列的书目列表
├── series.html             单个系列页：章节列表
├── reader.html             阅读器：翻页 / 连续滚动
├── assets/
│   ├── css/style.css       全站样式
│   ├── js/
│   │   ├── data.js         ★ 内容清单，加书/加话只改这个文件
│   │   ├── render-home.js
│   │   ├── render-series.js
│   │   └── render-reader.js
│   └── img/
│       ├── covers/         每个系列一张封面图
│       └── pages/          <系列id>/<话id>/p01.jpg ...
```

## 怎么添加一部新作品

1. 把扫图放进 `assets/img/pages/<系列id>/<话id>/`，命名成 `p01.jpg`、
   `p02.jpg`……三位数字对齐，避免 `p1, p10, p2` 这种排序错乱。
   （图片格式不限，jpg/png/webp 都行。）
2. 封面图放进 `assets/img/covers/<系列id>.jpg`。
3. 打开 `assets/js/data.js`，在 `MANGA_DATA.series` 数组里照着已有的样例
   复制一段，改成自己的标题、简介、标签、章节列表。
4. 每一话记得写对 `pageCount`（这一话总共多少页），阅读器是靠这个数字
   拼图片路径的。
5. 如果你的图片不是 `.svg`（示例占位图用的是 svg），记得把
   `data.js` 里 `chapterPageUrls()` 函数中的扩展名改成你实际用的格式。

现在仓库里放的是几组占位 svg 示例数据（花期 / 潮见坂 / 室内乐），方便你
先看效果；正式使用时把它们删掉换成自己的内容就行。

## 功能说明

- **首页**：按各系列"最新一话日期"倒序排列的书目列表，纯文字为主，
  留白克制，没有卡片和圆角阴影。
- **系列页**：封面 + 简介 + 章节列表。
- **阅读器**：
  - 默认「翻页」模式：点击图片左侧/右侧翻上一页/下一页，也支持键盘
    左右方向键、空格键。
  - 右上角按钮可以切换到「连续滚动」模式，整话图片纵向排列，
    适合手机上一口气看完。
  - 阅读模式偏好会记在浏览器本地（localStorage），下次打开自动沿用。
  - 一话读完会提示进入下一话，或者返回系列页。

## 部署到 GitHub Pages

1. 把这个文件夹的内容直接放进你的 `<你的用户名>.github.io` 仓库根目录
   （或者某个子目录，作为仓库里的一个 project page）。
2. 仓库 Settings → Pages，选择要发布的分支（通常是 `main`）和目录
   （根目录 `/` 或 `/docs`，看你放在哪）。
3. 保存后等一两分钟，`https://<你的用户名>.github.io/` 就能访问了。

因为整站是纯静态文件、没有 Hexo/Jekyll 之类的构建步骤，改完 `data.js`
直接 `git push` 就能生效，不需要本地生成。

## 想改样式

所有颜色、字体都写成了 CSS 变量，集中在 `assets/css/style.css` 顶部的
`:root` 里，改那几行就能换一套配色/字体，不用满文件找。

## 想加"仅自己可见"

GitHub Pages 本身不支持访问控制。如果需要私密备份，比较简单的做法是：
把仓库设为私有仓库 + 用 GitHub Pages 的付费版访问限制，或者干脆换成
Netlify / Cloudflare Pages 之类支持"密码保护"或"仅登录可见"的托管方式，
静态文件本身不用改。
